# Security Policy  ## Supported Versions  We release patches for security vulnerabilities. Which versions are eligible for receiving such patches depends on the CVSS v3.0 Rating:  | Version | Supported          | | ------- | ------------------ | | 1.0.x   | :white_check_mark: | | < 1.0   | :x:                |  ## Reporting a Vulnerability  **Please do not report security vulnerabilities through public GitHub issues.**  Instead, please report them via email to: **security@visionaicasting.com**  You should receive a response within 48 hours. If for some reason you do not, please follow up via email to ensure we received your original message.  Please include the following information in your report:  - Type of issue (e.g., buffer overflow, SQL injection, cross-site scripting, etc.) - Full paths of source file(s) related to the manifestation of the issue - The location of the affected source code (tag/branch/commit or direct URL) - Any special configuration required to reproduce the issue - Step-by-step instructions to reproduce the issue - Proof-of-concept or exploit code (if possible) - Impact of the issue, including how an attacker might exploit it  This information will help us triage your report more quickly.  ## Security Measures  ### Data Protection  - **Encryption at Rest:** All sensitive data is encrypted using AES-256 - **Encryption in Transit:** TLS 1.3 for all communications - **Database:** PostgreSQL TDE (Transparent Data Encryption) - **Backups:** Encrypted and stored in geographically distributed locations  ### Authentication & Authorization  - **Multi-Factor Authentication (MFA)** via Clerk - **Single Sign-On (SSO)** support - **Role-Based Access Control (RBAC)** with granular permissions - **Row-Level Security (RLS)** in PostgreSQL for tenant isolation - **JWT tokens** with short expiration and refresh token rotation  ### API Security  - **Rate Limiting:** Per-tenant and per-user limits - **Input Validation:** Strict validation with Pydantic schemas - **CORS:** Restricted to known origins - **API Keys:** Scoped and revocable for integrations  ### Infrastructure  - **WAF:** AWS Web Application Firewall - **DDoS Protection:** AWS Shield Standard - **VPC:** Isolated network environment - **Security Groups:** Minimal required access - **WAF Rules:** SQL injection, XSS, and common attack prevention  ### Compliance  - **LGPD (Brazil):** Full compliance with Brazilian data protection law - **GDPR:** Compliance for EU users - **SOC 2 Type II:** In progress - **Penetration Testing:** Quarterly third-party assessments  ## Disclosure Policy  When we receive a security bug report, we will:  1. Confirm receipt of the vulnerability report 2. Assess the impact and severity 3. Develop and test a fix 4. Release a security patch as soon as possible 5. Publicly disclose the issue after the patch is available (with credit to the reporter if desired)  We follow a 90-day disclosure timeline. If a fix is not available within 90 days, we will coordinate with the reporter on disclosure.  ## Security Best Practices for Users  ### For Administrators  - Enable MFA for all accounts - Regularly review user access and permissions - Keep your instance updated to the latest version - Monitor audit logs regularly - Use strong, unique passwords  ### For Developers  - Never commit secrets or API keys to version control - Use environment variables for sensitive configuration - Validate all user inputs - Keep dependencies updated - Follow the principle of least privilege  ### For End Users  - Use strong, unique passwords - Enable MFA if available - Be cautious of phishing attempts - Report suspicious activity immediately  ## Security Contacts  - **Security Team:** security@visionaicasting.com - **GPG Key:** [Download Public Key](https://visionaicasting.com/security-gpg-key.asc) - **Bug Bounty:** [HackerOne Program](https://hackerone.com/vision-ai-casting)  ## Acknowledgments  We would like to thank the following security researchers who have responsibly disclosed vulnerabilities:  - *List will be updated as reports are received*  ---  **Last Updated:** August 2026
