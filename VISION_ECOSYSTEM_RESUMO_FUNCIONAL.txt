1. O QUE E O VISION ECOSYSTEM
--------------------------------------------------------------------------------

O Vision e uma plataforma de inteligencia artificial voltada para profissionais
de imagem: atores, modelos, casting, figuracao, agencias e produtores.

A arquitetura segue o conceito de um "cerebro grande" (Vision Core) conectado a
varios "mini cerebros" especializados. Cada mini cerebro domina uma area e aciona
"motores" que executam tarefas pontuais.

O sistema nao depende de uma unica IA. Ele funciona como um ORQUESTRADOR capaz
de usar diferentes modelos, servicos e motores ao longo do tempo.

================================================================================

2. VISION CORE - CEREBRO CENTRAL
--------------------------------------------------------------------------------

O Vision Core e o orquestrador central. Ele:

- Recebe comandos do usuario (texto ou voz)
- Identifica a intencao do comando
- Cria contexto completo do usuario (perfil, memoria, historico)
- Escolhe o agente especializado correto para executar
- Emite eventos para todos os modulos interessados
- Solicita aprovacao humana quando necessario
- Registra tudo em logs de auditoria
- Retorna o resultado estruturado

Exemplo de comando:
  "Vision, cria uma postagem minha com perfil de executivo"

Fluxo:
  1. Vision Core recebe o texto
  2. Reconhece a intencao: CREATE_CONTENT
  3. Busca memoria do usuario (estilo, preferencias)
  4. Encaminha ao SocialAgent
  5. SocialAgent cria conteudo
  6. Retorna para aprovacao (nao publica sem autorizacao)
  7. Envia preview via WhatsApp com botoes APROVAR/ALTERAR/REJEITAR

3. MINI CEREBROS ESPECIALIZADOS (10 Agentes)
--------------------------------------------------------------------------------

Cada agente e um modulo independente que pode ser melhorado ou substituido sem
afetar os outros.

3.1 IDENTITY AGENT
    - Gerencia perfil e identidade do usuario
    - Atualiza dados pessoais e profissionais
    - Verifica identidade
    - Comandos: "atualiza meu perfil", "mostra meus dados"

3.2 VISAGISM AGENT
    - Analise completa de visagismo
    - Recomendacoes de estilo personalizadas
    - Colorimetria (tons que valorizam)
    - Cortes de cabelo ideais
    - Maquiagem recomendada
    - Ja funciona com IA real (OpenAI + AWS Rekognition)

3.3 DIGITAL TWIN AGENT
    - Construcao do "gemeo digital" profissional
    - Armazena fotos em multiplos angulos (frontal, perfil, 360)
    - Videos de referencia
    - Caracteristicas fisicas catalogadas
    - Estilo e visagismo registrados
    - Personagens ja realizados
    - FUTURO: simulacao realista para casting
      ("Como eu ficaria com barba de 3 dias nesse personagem?")

3.4 CASTING AGENT
    - Analise de oportunidades de casting
    - Comparacao de requisitos com perfil do usuario
    - Score de compatibilidade
    - Recomendacao de candidatura
    - Preparacao automatica de material
    - FUTURO: candidatura automatizada com aprovacao

3.5 PORTFOLIO AGENT
    - Gestao e otimizacao de portfolio
    - Selecao das melhores fotos
    - Organizacao por categoria
    - Sugestoes de atualizacao
    - Comandos: "atualiza meu portfolio", "qual foto usar para comercial?"

3.6 SOCIAL AGENT
    - Criacao de conteudo para redes sociais
    - Gera imagens (futuro: IA generativa)
    - Gera legendas personalizadas
    - Cria carrosseis
    - Planeja Reels
    - Adapta conteudo ao posicionamento profissional
    - SEMPRE solicita aprovacao antes de publicar
    - Comandos: "cria postagem", "faz um carrossel", "gera legenda"

3.7 OPPORTUNITY AGENT
    - Busca oportunidades no mercado
    - Matching com perfil do usuario
    - Alertas de vagas relevantes
    - Ranking de oportunidades por compatibilidade
    - Comandos: "procura oportunidades", "mostra as melhores vagas hoje"

3.8 APPROVAL AGENT
    - Gerencia workflows de aprovacao humana
    - Envia previews para WhatsApp
    - Processa respostas (APROVAR/ALTERAR/REJEITAR)
    - Se ALTERAR: recebe feedback, gera nova versao, reenvia
    - Garante que decisoes importantes sejam humanas

3.9 ANALYTICS AGENT
    - Analise de performance de conteudo
    - Coleta metricas de redes sociais
    - Identifica melhores horarios de postagem
    - Sugere melhorias baseadas em dados
    - Relatorios de carreira

3.10 AUTOMATION AGENT
    - Automacao de workflows repetitivos
    - Envio de notificacoes
    - Integracao entre agentes
    - Execucao de tarefas agendadas

4. FLUXO DE APROVACAO HUMANA (WhatsApp)
--------------------------------------------------------------------------------

Toda acao importante passa por aprovacao humana:

Vision gera publicacao
        |
        v
Envia preview para WhatsApp do usuario
        |
        v
Usuario recebe:
  [APROVAR] [ALTERAR] [REJEITAR]
        |
        +---> APROVAR: publica no canal configurado
        |
        +---> ALTERAR: usuario descreve mudancas
        |       |
        |       v
        |   Vision interpreta feedback
        |       |
        |       v
        |   Gera nova versao
        |       |
        |       v
        |   Volta para aprovacao
        |
        +---> REJEITAR: descarta e registra motivo

Objetivo: automacao extrema com decisao final humana.

6. BANCO DE MEMORIA
--------------------------------------------------------------------------------

O sistema mantem memoria estruturada do usuario:

- Historico de trabalhos realizados
- Tipos de personagem que ja fez
- Aparicoes aprovadas vs rejeitadas
- Preferencias esteticas
- Estilos de legenda que funcionam
- Agencias e contatos
- Resultados de castings anteriores
- Conteudos com melhor performance
- Feedbacks dados
- Decisoes anteriores

Essa memoria e consultavel por todos os mini cerebros para personalizar
respostas e recomendacoes.

9. EVENTOS E AUDITORIA
--------------------------------------------------------------------------------

Todo evento importante e registrado:

- Usuario criado, perfil atualizado
- Casting criado, analisado
- Conteudo criado, aprovado, publicado
- Tarefa de IA criada, completada, falhou
- Aprovacao solicitada, aprovada, rejeitada
- Workflow iniciado, completado

Cada acao gera um AuditLog com:
- Quem fez (usuario, agente)
- O que foi feito (acao)
- Em quem (entidade, ID)
- Estado anterior (before)
- Estado novo (after)
- IP e navegador
- Data e hora

Isso permite investigacao completa de qualquer incidente.

13. EXEMPLOS DE USO
--------------------------------------------------------------------------------

CENARIO 1: Ator quer se candidatar a um casting
---------------------------------------------
Usuario: "Vision, tem algum casting para ator de 30 anos?"
Vision: (OpportunityAgent busca)
        "Encontrei 3 oportunidades. A mais compativel e:
         'Protagonista serie policial' - 95% match
         Precisa de foto dramatica e video de 30s"

Usuario: "Prepara minha candidatura"
Vision: (CastingAgent + DigitalTwinAgent)
        1. Seleciona melhores fotos do portfolio
        2. Gera simulacao do personagem
        3. Prepara video de apresentacao
        4. Organiza dados do perfil
        5. Cria resposta personalizada
        6. ENVIA PARA APROVACAO via WhatsApp

Usuario: (no WhatsApp) [APROVAR]
Vision: (CastingAgent)
        Envia candidatura oficial
        Registra no historico

CENARIO 2: Modelo quer postar no Instagram
-----------------------------------------
Usuario: "Cria uma postagem minha estilo editorial"
Vision: (SocialAgent)
        1. Analisa perfil e estilo
        2. Seleciona melhor foto do portfolio
        3. Gera legenda editorial
        4. Seleciona hashtags
        5. Cria preview
        6. ENVIA PARA APROVACAO via WhatsApp

Usuario: (no WhatsApp) [ALTERAR] "Mais elegante, menos hashtags"
Vision: (SocialAgent)
        1. Interpreta feedback
        2. Gera nova versao
        3. Reenvia para aprovacao

Usuario: (no WhatsApp) [APROVAR]
Vision: (SocialAgent + InstagramConnector)
        Publica no Instagram
        Registra metricas

CENARIO 3: Analise de perfil completa
-------------------------------------
Usuario: "Faz uma analise completa do meu perfil"
Vision: (VisagismAgent + FacialAnalysis + Colorimetry + Branding)
        1. Analisa todas as fotos do portfolio
        2. Visagismo completo
        3. Colorimetria pessoal
        4. Expressoes catalogadas
        5. Personal branding
        6. Grooming
        7. Gera relatorio PDF profissional
        8. Envia para download

14. RESUMO EXECUTIVO
--------------------------------------------------------------------------------

O Vision Ecosystem e uma plataforma que usa inteligencia artificial para
automatizar e potencializar a carreira de profissionais de imagem.

Em vez de o ator/modelo precisar:
- Ficar procurando casting manualmente
- Criar conteudo para redes sociais todo dia
- Decidir qual foto usar
- Escrever legendas
- Se candidatar a vagas
- Analisar seu proprio perfil

O Vision faz tudo isso automaticamente, mas sempre com aprovacao humana
final. O profissional mantem o controle, mas nao precisa fazer o trabalho
repetitivo.

A arquitetura e modular: cada funcionalidade e um "mini cerebro" que pode
ser melhorado ou substituido. O sistema nao depende de nenhuma empresa ou
tecnologia unica.

A memoria do sistema aprende com o tempo: sabe o que funcionou, o que nao
funcionou, as preferencias do usuario, e usa isso para melhorar recomendacoes.
