## 6. CABELO, BARBA, SOBRANCELHAS E MAQUIAGEM

### Cabelo atual (nas fotos):
- **Comprimento:** Curto nas laterais (fade baixo), 4-6cm no topo
- **Textura:** Natural, levemente despenteado
- **Cor:** Castanho escuro com branco significativo nas têmporas (~30-40%)
- **Estilo:** Moderno, desconstruído, com movimento no topo

### Recomendação para cabelo:

**Recomendação: MANTER o estilo atual com ajustes**

| | |
|---|---|
| **Objetivo visual** | Preservar modernidade e autenticidade |
| **Fundamentação** | O "salt and pepper" nas têmporas é diferencial de caráter. O corte atual já é moderno. |
| **Como executar** | Manter fade baixo nas laterais. Reduzir ligeiramente o volume no topo (está um pouco alto em algumas fotos). Manter textura natural. NÃO cobrir o branco. |
| **Aplicações** | Casting geral, comerciais, figuração, publicidade |
| **Alternativas** | Se quiser mais conservador: taper ao invés de fade. Se quiser mais ousado: fade médio + volume maior no topo. |
| **Riscos** | Volume excessivo no topo pode parecer desproporcional em certos ângulos |
| **Impacto** | ALTO |
| **Confiança** | ALTA |

### Barba atual (nas fotos):
- **Comprimento:** Média curta, bem definida (~5-8mm)
- **Linhas:** Definidas no pescoço e bochechas
- **Cor:** Grisalha predominante, mais escura nas bochechas
- **Formato:** Cobre maxilar e queixo, conecta ao bigode

### Recomendação para barba:

**Recomendação: MANTER com ajustes de definição**

| | |
|---|---|
| **Objetivo visual** | Maximizar definição facial e transmitir maturidade controlada |
| **Fundamentação** | A barba grisalha é um dos seus maiores ativos visuais. Define o maxilar e adiciona autoridade. |
| **Como executar** | Manter comprimento atual. Reforçar linhas do pescoço (deixar mais definidas). Aparar bochechas para não subir muito alto. Manter bigode conectado. |
| **Aplicações** | Ator de caráter, figuração, publicidade institucional |
| **Alternativas** | Para look mais jovem: reduzir a barba para shadow (2-3 dias). Para look mais dramático: deixar crescer por 2-3 semanas. |
| **Riscos** | Barba muito longa pode parecer descuidada; muito curta perde o diferencial grisalho |
| **Impacto** | ALTO |
| **Confiança** | ALTA |

### Sobrancelhas:
- **Avaliação:** Boas, naturais, densidade adequada
- **Recomendação:** Tirar apenas pelos fora do arco natural. NÃO fazer design dramático.

### Maquiagem:
- **Limite declarado:** Não usar
- **Alternativa:** Cuidados com a pele (limpeza, hidratação, protetor solar)

## 11. PERFORMANCE, ATUAÇÃO E PRESENÇA DIANTE DA CÂMERA

### Avaliação baseada nas fotos:

**Pontos fortes observáveis:**
- Sorriso genuíno e contagiante (transmite acessibilidade)
- Olhar direto e confiante
- Postura corporal aberta (não defensiva)
- Presença de "cara de bem" — transmite confiança

**Pontos a desenvolver:**
- Variação de expressões (fotos mostram principalmente sorriso e neutra)
- Controle de intensidade do sorriso (em algumas fotos parece forçado)
- Relaxamento facial para expressões mais sutis

### Exercícios recomendados:

**1. Neutralidade facial (5 min/dia):**
- Frente ao espelho, expressão completamente neutra
- Relaxar testa, sobrancelhas, boca
- Olhar fixo por 30 segundos
- Fotografar e comparar

**2. Variação de intensidade do sorriso:**
- Sorriso 10% (quase imperceptível)
- Sorriso 50% (sutil, olhos participam)
- Sorriso 100% (amplo, como nas fotos atuais)
- Praticar transições entre eles

**3. Microexpressões:**
- Surpresa controlada (sobrancelhas levantadas, boca fechada)
- Pensamento (olhar para baixo, leve franzir)
- Aprovação (aceno sutil, canto da boca)
